# BMD repair handoff

## Goal
Fix the bending moment diagram (BMD) calculation so it is structurally correct for mixed load cases, especially when point loads and UDLs are combined.

## Why this is a real structural issue
The governing relationship is:

$$
\frac{dM}{dx} = V
$$

This must hold away from discontinuities created by point loads and UDL starts/ends. The existing BMD implementation is still not giving a moment curve whose slope matches the computed shear distribution in the mixed-load case.

This is not just a rendering bug. It is a beam-statics calculation bug.

## Files involved
- `js/analysis/bending.js` — main BMD solver
- `js/analysis/shear.js` — shear distribution used as the reference
- `js/analysis/reactions.js` — reaction solving, supports, UDL resultant moments
- `js/state/store.js` — beam model arrays and length access
- `tests/beam-analysis-regression.mjs` — regression validation

## What has already been learned
1. The failure is reproducible and isolated to the mixed-load BMD case.
2. Simple point-load and simple UDL cases are basically working.
3. The underlying bug is in the way the BMD is constructed when combining:
   - support reactions,
   - point loads,
   - and UDLs with varying intensity over a span.
4. The BMD must be generated by exact piecewise shear integration across critical beam points, not by ad hoc formulas that approximate the moment from one cumulative expression.
5. Discontinuities must be handled carefully because the moment derivative is undefined exactly at concentrated load and UDL transition points.

## Correct approach to finish
The next agent should rebuild the BMD generation in a mathematically correct way:

1. Compute the reaction forces first.
2. Build the set of critical beam points:
   - beam start
   - beam end
   - support locations
   - point load locations
   - UDL start and end locations
3. Evaluate shear on each interval using exact load accumulation.
4. Integrate shear piecewise between critical points to get moment.
5. Treat discontinuity points carefully and skip them in the derivative-by-finite-difference validation.
6. Re-run the regression suite and ensure all cases pass.

## Engineering principle to keep in mind
A correct BMD must satisfy:

- moment is continuous between load discontinuities
- slope of M equals V between discontinuities
- jumps in shear cause changes in moment slope
- the moment at a support or free end is set from equilibrium, not from an approximate averaging formula

## Important warning
Do not patch only obvious cases one by one. The issue is systemic: the mixed-load BMD generation needs a mathematically consistent formulation, not a targeted patch.
